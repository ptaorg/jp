# 第14章差し替え用ZIP

## 内容

このZIPは、`ptaorg/jp` リポジトリの第14章だけを差し替えるための最小セットです。

入っているファイルは4つです。

1. `apply_chapter14_patch.py`
   - `docs/guideline.md` の第14章を差し替えます。
   - `index.html` の第14章 section を差し替えます。

2. `chapter14_guideline_replacement.md`
   - `docs/guideline.md` に入れる第14章本文です。

3. `chapter14_index_replacement.html`
   - `index.html` に入れる第14章 section です。

4. `README_適用方法.txt`
   - この説明ファイルです。

## 適用方法

1. ZIPを展開する。
2. `apply_chapter14_patch.py` を、`ptaorg/jp` リポジトリのルートに置く。
   - `index.html` がある場所です。
3. ターミナルで次を実行する。

```bash
python apply_chapter14_patch.py
```

4. 次の2ファイルだけが更新されます。

- `docs/guideline.md`
- `index.html`

## 変更内容

第14章「根拠資料の確認」を、単なる資料リンクではなく、本文全体の信頼性を支える章として整えます。

追加される内容は次のとおりです。

- 法令、国の通知・行政資料、PPC資料、消費者庁資料、自治体通知・回答を区別して扱うこと
- 法令は全国共通の根拠、通知・行政資料は実務上の補助資料、自治体回答は個別運用・見解として扱うこと
- 学校施設、個人情報、教職員関与の論点ごとに、どの根拠資料と対応させて確認するか
- 未確認の自治体通知・回答は、正式URL、本文、発出日、文書画像、回答主体を確認するまで断定引用しないこと
- 一次資料台帳は本文の代替ではなく、根拠を追跡するための管理資料であること
